# 📊 Ecommerce Data Engineering Project (Microsoft Fabric)

## 🚀 Overview

This project demonstrates an end-to-end Data Engineering pipeline using Microsoft Fabric and Power BI.

## 🧩 Architecture

CSV → Lakehouse → PySpark → Silver → Gold → Power BI Dashboard

## ⚙️ Technologies Used

* Microsoft Fabric
* PySpark
* Power BI
* Lakehouse Architecture

## 🔄 Data Pipeline

1. Data Ingestion (CSV)
2. Data Transformation using PySpark
3. Medallion Architecture:

   * Bronze (Raw)
   * Silver (Cleaned)
   * Gold (Aggregated)
4. Visualization using Power BI

## 📊 Dashboard Insights

* Sales by Region
* Total Sales KPI
* Sales Distribution

## 💼 Use Case

Helps business analyze regional sales performance and make data-driven decisions.
